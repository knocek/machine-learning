### What's here?
- Data visualization
- Python basic

- ...

### How to use it?

1. Create and activate your venv.
```bash
python -m venv .venv
.venv\Scripts\Activate.ps1
```
2. Update pip and python version.
```bash
pip install --upgrade pip
```
3. Install requirements.
``` bash
pip install -r requirements.txt
```
4. Set jupyter kernel.
```bash
python -m ipykernel install --user --name=your_name --display-name "your kernel name"
```
5. VS Code:
- Ctrl + Shift + P
- Python: Select Interpreter
- choose: .venv\Scripts\python.exe
- in notebook: choose "your kernel name"
